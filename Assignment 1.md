1. I type a website address into the browser.
2. I press Enter to open the website.
3. The browser checks whether it has saved information about the website.
4. It looks up the website’s address so it can find the right server.
5. The browser connects to that server.
6. If the website is secure, the browser sets up an encrypted connection.
7. The browser asks the server for the page.
8. The server receives and processes the request.
9. The server sends the page back to the browser.
10. The browser reads the page’s HTML and builds its structure.
11. It loads extra files, such as pictures, styles, and scripts.
12. The browser arranges everything and displays the page on the screen.
